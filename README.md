# Bank Queue Management System (Java Console) 🏦🔢

โปรเจกต์จำลองระบบจัดการคิวธนาคาร พัฒนาด้วยภาษา **Java** โดยเน้นการใช้โครงสร้างข้อมูลประเภท **Queue** เพื่อจัดการลำดับการเข้ารับบริการของผู้ลูกค้าอย่างมีประสิทธิภาพ

---

## 🔍 ภาพรวมของโปรเจกต์

ระบบถูกออกแบบมาเพื่อจำลองการทำงานของเคาน์เตอร์บริการในธนาคาร โดยรองรับการรับคิวใหม่ การเรียกคิวถัดไปเพื่อเข้ารับบริการ และการแสดงสถานะคิวปัจจุบันทั้งหมด โปรเจกต์นี้แสดงให้เห็นถึงการประยุกต์ใช้ Data Structure พื้นฐานในสถานการณ์จริง

---

## 🛠️ เทคโนโลยีที่ใช้

- **Language**: Java 8+
- **Data Structure**: `java.util.LinkedList` (Implementation of Queue)
- **Input Handling**: `java.util.Scanner`
